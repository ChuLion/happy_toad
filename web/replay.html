Ask about budget scenarios. A checker traces every number in the answer to a stored run. All data is synthetic.

How an answer is made
  1. QuestionYou ask in plain English.
  2. AgentTurns it into exact scenario requests.
  3. GateAccepts or rejects each request, listing every problem. Rejected: stored with its reasons, not solved.
  4. OptimizerMost weighted relief first, then the lowest spend for it.
  5. Run recordEvery attempt is stored with a run id.
  6. ReportA summary, with its numbers listed as claims.
  7. CheckerMatches every number to a stored run. Mismatch: sent back to the agent once.
  8. YouSee the label and the numbers. A human decides.
