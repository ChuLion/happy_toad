Capital Planning Scenario Assistant

Ask about budget scenarios. A checker traces every number in the answer to a stored run. All data is synthetic.

How an answer is made

AI modelCode Feedback to the agent

  1. QuestionA planner asks in plain English.
  2. IntakeTurns it into exact scenario requests.
  3. GateAccepts or rejects each request, with every problem.
  4. Rejected: back to the agent with every reason
  5. rejected
  6. accepted
  7. OptimizerMost weighted relief, then the lowest spend for it.
  8. Run recordEvery attempt is stored with a run id.
  9. stored runs
  10. ExplanationA summary, its numbers listed as claims.
  11. CheckerMatches every number to a stored run.
  12. Refused: back to the agent
  13. CHECKED, NOT CHECKED or NO NUMBERS TO CHECK
  14. Human reviewSees the label and the numbers, and decides.
