Capital Planning Scenario Assistant

Ask about budget scenarios. A checker traces every number in the answer to a stored run. All data is synthetic.

How an answer is made

AI modelCode Feedback to the agent

  1. QuestionA planner asks in plain English.
  2. IntakeTurns the question into exact scenario requests.
  3. GateAccepts or rejects each request, listing every problem. Rejected: back to the agent with every reason.
  4. OptimizerMost weighted relief first, then the lowest spend for it.
  5. Run recordEvery attempt is stored with a run id.
  6. ExplanationA summary, with its numbers listed as claims.
  7. CheckerMatches every number to a stored run. Refused: back to the agent.
  8. Human reviewSees the label and the numbers. A human decides.
